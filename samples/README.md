# Sample tracks

Audio files in this folder appear under **Sample tracks** in the *Stems* and *Transcribe* panels, so anyone who opens the app can play along without uploading anything.

**Add your own:** drop an `.m4a`, `.mp3`, `.wav`, `.ogg` or `.flac` file here, optionally give it a title in `info.json`, then run `npm run build` (it regenerates `manifest.json`) and commit. Keep files modest (a few MB each): the browser downloads a track only when someone taps it.

Only add music you own or have the right to share. Everything committed to a public repository is public.
