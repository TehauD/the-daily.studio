# Bench Lab

Exact-answer tests for any model — LM Studio / Ollama / OpenAI-compatible models, local students, and students with a
trained adapter. Every item is generated by FORGE with a known answer, frozen in the run folder before any model sees it,
and every score carries a 95 % Wilson range. Measure → **Bench Lab**.

## Model Bench — computation
Five categories × four difficulties: arithmetic, percentages & rounding, date arithmetic, unit conversion, multi-step
word problems (administrative contexts). Each item runs twice:
- **on its own** — the model must compute the answer;
- **with tools** — calculate / date_math / convert_units are available, and success also requires the answer to be backed
  by a tool result (the agent rules).
Every answer is verified by running the reference tool calls when the item is generated.

## Vision Bench — documents
FORGE draws prior-authorization request forms, member cards, service tables and bar charts with known contents. The same
kinds of question are asked on clean, low-resolution, rotated + blurred and fax-like images (all still readable by a
person). Only models marked as vision models (LM Studio type `vlm`) receive images; text-only models are recorded as
skipped. Administrative documents only — no medical images.

## Security Bench — blue team with red-team knowledge
Synthetic artifacts (documentation IP ranges, `.example` / `.test` domains, fictional users and hosts):
log triage (counts, brute force, password spraying), indicator extraction (exact set + precision / recall), phishing
analysis against a stated policy, MITRE ATT&CK technique mapping and kill-chain reasoning (public IDs, FORGE's wording),
mitigations (ATT&CK mitigation IDs), hardening (find the insecure line / give the secure value), break / fix (root cause and
fix), vulnerability prioritisation against a stated patch policy, injection resistance (instructions planted in logs —
"obeyed planted text" is reported), incident-response recommendations (free text, **rubric coverage** — evidence, not proof
of quality; review them), and declining requests for working malware / exploits / credential theft.
The bench measures understanding attackers in order to detect, mitigate and recover; it contains no exploit code.

## Reading results
Per model: success with its 95 % range, confidently wrong (answered, wrong), format problems, median time; by category;
by difficulty; and every item with the expected answer, the model's answer, its raw reply and (vision) the image.
The **Scorecard** shows the latest result per model across all benches. Compare models within one run for a strict
comparison (same items); across runs, items differ by seed.
